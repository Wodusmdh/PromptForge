# PromptForge Developer Playground

## Objective
The PromptForge Developer Playground is an interactive web application that allows developers to experiment with the Compiler, Rule Intelligence, and Optimization engines in real time. It serves as a visual workbench for building and debugging complex LLM prompts.

## Architecture

The Playground is built as a modular React application that strictly acts as a consumer of the PromptForge API (`/api/v1`). It contains zero duplicate compilation logic.

- **UI Components**: Built with React and Tailwind CSS.
- **State Management**: React Context (`PlaygroundContext`) manages global application state across panels.
- **API Client**: A dedicated fetch-based client wrapper for the REST endpoints.

## Features
- **Prompt Editor**: A code editor for defining ideas, with live token estimation.
- **Live Preview**: Inspect the original, compiled, and optimized prompt variants side-by-side.
- **Rule Explorer**: A search interface querying the Rule Intelligence subsystem to browse injected guidelines.
- **Engine Inspector**: View which compiler engines were activated and their execution status.
- **Validation Panel**: Surface errors and warnings generated by the Compiler's validation pipeline.
- **Benchmark View**: Compare token usage and optimization efficiency.
- **Execution History**: Maintain a session history of compilations to restore or compare iterations.
